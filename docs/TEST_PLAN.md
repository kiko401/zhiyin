| --- | --- |

| 编制日期 | 2026 年 11 月 7 日 |

| 关联文档 | PRD 第 8 章（用例编号体系）、Web 原型设计文档第 9/12 章 |

## 1 概述

本计划覆盖知音 Web 原型的功能与质量验证：主链路（五径）、接口契约、故障注入、合规边界、边界值与安全隔离。测试结论记录于 docs/TESTING.md（测试报告）。

## 2 测试范围

**包含**：

- F 主链路（五径端到端、追问继承、幂等重放）
- API 契约（33 接口逐个冒烟：鉴权、响应包络、错误码）
- E 故障注入（模型开关、数据源故障、iFinD 缺失、调度器停摆、超长输入、XSS 载荷）
- C 合规（R1 红线扫描、AI 标识与免责、澄清轮次上限、跨用户隔离）
- LX/PF（词典消解与改回、画像三态授权与删除导出）
- T 任务链路（委托全链路、简报契约、生命周期、频控、引擎降级）
- 边界值（输入截断、并发排队、会话过期、种子数量校验）

**不包含**（原因）：

- 性能压测（单容器演示负载，非本轮目标）
- 多浏览器兼容（桌面 Chrome 为验收环境，响应式为代码约定）
- 移动端原生能力（Web 原型无原生功能）

## 3 测试环境

| 项 | 值 |
| --- | --- |
| 被测方式 | 本地 uvicorn + SSH 隧道连接服务器测试库（zhiyin_test_db / Redis，与生产同构 MySQL 8 / Redis 7） |
| 测试数据 | data/ 种子（词典 400、金标 60、底稿 5 家）+ 注册的测试账号 |
| 注入手段 | 环境开关（LLM_ENABLED / SCHEDULER_ENABLED / IFIND 置空）+ monkeypatch（扶摇超时/零命中） |
| 外部依赖 | 扶摇 API（真实调用，限流退避）；DeepSeek 研究模型与判分模型 |

## 4 测试策略

分层执行，下层通过才进上层：

1. **接口冒烟**：33 接口逐个调用，校验鉴权（未登录 40402）、响应包络 `{code,message,data}`、错误码（40001/42901/40401/50301）。
2. **主链路**：五径各一条端到端（对话 → 澄清/规格 → 任务 → 交付），校验卡片类型与状态机转移。
3. **故障注入**：以开关与 mock 触发 E1/E3/E10/E11/E8/E9，校验降级显式、不静默。
4. **合规边界**：红线样本集零漏放、澄清 2 轮硬上限、跨用户 404。
5. **边界值**：输入 1000 字截断、并发 Semaphore(8) 排队、会话过期。

## 6 准入准出

- **准入**：M1–M6 冒烟全过；seed.py 在测试库执行成功。
- **准出**：P0 用例 100% 通过；P1 通过率 ≥ 95%；阻塞/严重缺陷清零；一般缺陷全部记录于测试报告。

## 7 进度与角色

单人 + 自动化（pytest）。执行顺序：smoke 集（约 8 分钟）→ full 集（约 10 分钟）→ 缺陷修复回归 → 报告。

## 8 风险

- 扶摇真实调用受限流影响：用例内置退避；CI 化不在本轮范围。
- 模型输出非确定性：判分与断言聚焦结构合规（引用四要素、无红线词）而非具体措辞。
